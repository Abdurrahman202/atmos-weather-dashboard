
# Atmos — Live Weather Experience

A modern, responsive weather dashboard built with HTML, CSS, and JavaScript. Atmos retrieves weather information from the Open-Meteo API and displays current conditions, weather metrics, and a five-day forecast.

## Features

- Live weather information for cities worldwide
- City search with location lookup
- Current temperature and feels-like temperature
- Daily high and low temperatures
- Humidity, wind speed, precipitation, and UV index
- Five-day weather forecast
- Dynamic weather icons and weather insights
- Loading indicators and API error handling
- Responsive desktop, tablet, and mobile layouts
- Accessible navigation and reduced-motion support

## Tech Stack

- HTML5
- CSS3
- JavaScript (ES6+)
- Fetch API and async/await
- Open-Meteo Geocoding API
- Open-Meteo Forecast API
- Lucide icons

## Getting Started

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Launch `index.html` using the Live Server extension.
4. Make sure you have an internet connection.
5. Search for a city to view its weather information.

No API key is required for normal non-commercial use of Open-Meteo.

## Weather Data

Weather information is provided by Open-Meteo.

- Geocoding: https://geocoding-api.open-meteo.com/
- Forecast: https://open-meteo.com/

Weather information can change, and availability depends on the external API.
